# قارورة الحليب — Milk Bottle

لعبة مغامرة 2D توب-داون بالجافاسكريبت الصرف. شغّلها عبر خادم محلي (الأصول تُحمَّل بـ fetch/video):

    python3 -m http.server 8000   # ثم افتح http://localhost:8000

## الأصول (`assets/`، مدمجة بالكامل)
- `MOVE/` `KICK/` قارب نور (تجديف / ضربة المجداف = الاندفاع) · `KID_WALK/` مشي نور على الجزر
- `SHARK/MOVE|ATTACK|TAKE DAWN` القرش: سباحة / مطاردة وعضّ / تهدئة (التناغم) · `DOLPHIN/*` الدلفين: رفيق، ظهر الدلفين (Shift)، قفزة النهاية، إنقاذ عند فقدان الشجاعة
- `ISLAND/` الجزر الآمنة وجزيرة النهاية ومذبح المنارة · `props/` القارورة والقارب الراسي
- `story/` لوحات المقدمة + الإطار · `menu/` فيديو القائمة وفيديو الانتقال
- أعد توليد `js/manifest.js` بعد تغيير الإطارات: `python3 tools/build_manifest.py`

## الكود
`js/story.js` القصة · `js/levels.js` ستة فصول · `js/game.js` المحاكاة · `js/sprites.js` الإطارات · `js/render.js` الرسم · `js/hud.js` الواجهة · `js/audio.js` صوت إجرائي · `js/main.js` الشاشات والمدخلات.
`legacy/` كود اللعبة القديمة للمرجعية فقط.

## الحلقة
اتبع اللمعة → تجنّب القرش → حلّ لغز الفصل → اكسب قدرة → انزل أعمق. القدرات: ضربة المجداف (Space) · فانوس (F) · صدفة رنّانة (Q) · الدلفين (Shift) · تناغم (E). النهاية اختيار: إعادة النور أو الاحتفاظ بالقارورة.
