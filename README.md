# قارورة الحليب — Milk Bottle

لعبة مغامرة 2D توب-داون بالجافاسكريبت الصرف (بدون أصول خارجية، كل الرسم والصوت إجرائي).
افتح `index.html` مباشرةً في المتصفح، أو شغّل `python3 -m http.server`.

## البنية
- `js/story.js` القصة والنهايتان · `js/levels.js` ستة فصول (بيانات) · `js/game.js` المحاكاة (لاعب، قرش، ألغاز، تقدّم)
- `js/render.js` الرسم · `js/hud.js` واجهة HUD · `js/audio.js` الصوت · `js/main.js` المدخلات وتدفق الشاشات

## الحلقة
اتبع اللمعة → تجنّب القرش → حلّ لغز الفصل → اكسب قدرة → انزل أعمق.
القدرات: اندفاع (Space) · فانوس (F) · صدفة رنّانة (Q) · غطس (Shift) · تناغم (E).
النهاية الأخيرة اختيار: إعادة النور للبحر أو الاحتفاظ بالقارورة.
